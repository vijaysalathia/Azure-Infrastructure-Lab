# Azure-Infrastructure-Lab
This repository demonstrates hands-on implementation of Azure infrastructure and Windows Server environments, including Active Directory, networking, VPN, and hybrid cloud integration.


azure-infrastructure-lab/
├── 01-Networking/
├── 02-VM-Deployment/
├── 03-Active-Directory/
├── 04-VPN-Gateway/
├── 05-Web Server/
├── 06-Azure Integration/
└── screenshots/


---

## Objective

To gain practical, real-world experience in designing and deploying secure Azure-based infrastructure with hybrid identity and networking.

---

## Key Learnings

- End-to-end Azure infrastructure deployment
- Hybrid identity integration (On-prem AD + Azure)
- Secure remote connectivity using VPN
- Real-world enterprise-level configuration
