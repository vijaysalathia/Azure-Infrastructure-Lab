# Active Directory Domain Services (AD DS)

##  Objective
To deploy and configure Active Directory Domain Services (AD DS) on Windows Server and manage users, policies, and shared resources in a domain environment.

---

##  Domain Controller Setup

- Installed Active Directory Domain Services (AD DS) role
- Promoted server to Domain Controller
- Created new forest and domain
- Configured DNS during AD setup

---

##  User & Organizational Unit (OU) Management

- Created Organizational Units (OUs) for structured management
- Added users and groups within OUs
- Applied administrative controls using AD Users and Computers

---

##  Client Machine Domain Join

- Configured client machine network settings
- Connected client machine to domain
- Verified domain login using domain credentials

---

##  Home Folder Configuration

- Created shared folder on server
- Assigned user-specific home directories
- Configured NTFS permissions for secure access

---

##  Drive Mapping using Group Policy (GPO)

- Created Group Policy Object (GPO)
- Configured drive mapping for users
- Automatically mapped network drives upon login

---

##  Group Policy Management

- Applied policies to control user environment
- Managed access restrictions and system settings
- Linked GPOs to specific OUs

---

##  Key Learnings

- End-to-end AD DS deployment and configuration
- Centralized user and resource management
- Importance of Group Policy in enterprise environments
- Secure file sharing using permissions and policies
