# Azure Integration (Entra ID & Hybrid Identity)

##  Objective
To integrate on-premises Active Directory with Azure Entra ID and enable hybrid identity and device management.

---

##  Azure Entra ID Overview

- Azure Entra ID (formerly Azure AD) is a cloud-based identity and access management service
- Used to manage users, authentication, and access to cloud resources

---

##  Azure User & Admin Creation

- Created users in Azure Entra ID
- Assigned administrative roles
- Managed user access for cloud resources

---

##  AD Integration with Azure Entra ID

- Configured synchronization between on-prem AD and Azure Entra ID
- Enabled identity consistency across environments
- Verified user presence in Azure portal

---

##  Hybrid Azure AD Join

- Configured devices for Hybrid Azure AD Join
- Domain-joined machines registered in Azure Entra ID
- Verified device status:
  - Azure AD Joined / Hybrid Joined

---

##  Identity Flow

- Users created in on-prem AD
- Synced to Azure Entra ID
- Devices join domain and register with Azure
- Authentication works across both environments

---

##  Benefits of Integration

- Single identity across on-prem and cloud
- Centralized access control
- Improved security and compliance
- Seamless user experience

---

## 🧠 Key Learnings

- Understanding hybrid identity architecture
- Integration between AD DS and Azure Entra ID
- Device registration and identity synchronization
- Role-based access control in Azure
