# Compute & VM

##  Objective
To deploy and configure a Windows Server Virtual Machine in Azure and enable secure remote access.

---

##  Virtual Machine Deployment

- Created a Windows Server Virtual Machine in Azure
- Selected appropriate region and VM size for lab usage
- Configured administrator username and password
- Associated VM with a Virtual Network (VNet)

---

##  Static IP Configuration

- Assigned a private static IP to the Virtual Machine
- Ensured consistent internal communication within the network
- Verified IP configuration using: ipconfig

  
---

##  Remote Desktop (RDP) Access

- Enabled RDP access during VM creation
- Connected to VM using Remote Desktop from local machine
- Used Public IP address for remote login
- Verified successful login and server accessibility

---

##  Key Learnings

- Understanding Azure VM deployment process
- Importance of static IP for server roles
- Secure remote access using RDP
- Basics of Azure networking integration with VM
